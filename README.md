# 四级搭配背卡（CET-4 Collocation Cards）

把《四级真题高频搭配与句式精析》里的 **357 条高频搭配、句式**做成一个能装进手机的背单词小 App。
白底黑字、大字、没有花哨动画，只有一个目的：**每天被考一遍，错的过两天再考一遍。**

同一个页面有两种用法：

- **网页版**：`index.html` 一个文件，双击就能用，不需要联网、不需要安装任何东西。
- **安卓版**：`cet4-cards.apk`，装到手机上，桌面名字叫「四级背卡」。

> 进度都存在这台设备自己的浏览器里（localStorage），不上传、不联网。
> 换手机用「备份进度」生成一串短码，发给自己就行。

## 它长什么样

首页三个数字（已学 / 今天待复习 / 今天答了）、打卡日历、距考试倒计时，然后选背法、选分类、开刷。

| 功能 | 说明 |
| --- | --- |
| 两段判定 | 先看题 →「我想到了 / 想不起来」→ **都先翻出答案** →「确实对 / 有点模糊 / 记错了」。防"看答案才算认识"的自欺。 |
| 间隔复习 | 答对往后推 1 / 3 / 7 / 15 / 30 天；有点模糊 = 明天再来一次；记错 = 清零 + 当天重现。 |
| 四种背法 | 看英文猜意思 / 看中文想英文 / 例句挖空 / 听音辨词。 |
| 极速刷词 | 通勤专用：英文中文一起给，右滑划走、左滑留下，剩下的自动进下一轮，直到全认识。10 分钟能过几百张。 |
| 错题本 | 答错过的卡按错得多少排序，可以一键"狂刷错题"。 |
| 收藏 | 星标 + 只看收藏，考前只刷自己标过的。 |
| 打卡日历 | 最近 8 周，颜色越深答得越多；连续天数显示在首页。 |
| 手感 | 左右滑卡、撤销上一步、搜词直达单卡、例句默认先藏、字号 6 档、夜间模式。 |
| 备份 | 备份码 v2 只有 176 个字符（比 v1 短 6 倍），旧码也还能读。 |

## 目录

```
index.html            成品单文件网页（由模板 + 数据生成，可直接双击打开）
cet4-cards.apk        成品安卓安装包（versionCode 5 / 1.5）
app_template.html     网页模板：样式 + 全部交互逻辑，含 __DATA__ 占位
cards.json            357 条卡片数据 {en 英文, zh 中文, ex 真题例句, cat 分类}
build_cards.py        把 cards.json 注入模板 → index.html
extract_cards.py      从原始 docx 抽卡片 → cards.json（需要你自己有那份 docx）
android/              安卓壳工程：WebView + 本地 http 服务 + 构建脚本
```

## 自己重新生成

```bash
python build_cards.py      # 改完 app_template.html 或 cards.json 后跑这个
```

安卓包需要本机装 JDK 17 + Android build-tools 35 + platform-35，然后改 `android/build_apk.sh`
顶部的工具链路径，再执行：

```bash
cd android && bash build_apk.sh
```

## 实现上值得说的两点

1. **进度为什么不丢**：安卓版没有直接把网页丢进 `file://`（那里 localStorage 常被清掉或禁用），
   而是在 App 里起了个只监听 `127.0.0.1` 的小 http 服务（`LocalServer.java`），
   让 WebView 以正常的 http 源打开页面，进度就稳定存在 WebView 的存储里了。
2. **发音**：优先用系统 TTS；安卓 WebView 通常不支持，就退回有道词典的发音接口（需要联网）。
